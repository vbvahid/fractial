# فریکشن (Fractial)

ابزار محاسبات کسری، بزرگترین مقسوم مشترک (GCD)، کوچکترین مضرب مشترک (LCM) و ساده‌سازی کسر — کاملاً سمت‌کلاینت، بدون سرور، برای استقرار روی Cloudflare Pages.

## ویژگی‌ها
- **عملیات چهارگانه روی دو کسر**: جمع، تفریق، ضرب، تقسیم — نمایش هم‌نام‌ساده‌شده و ساده‌شده
- **GCD / LCM**: محاسبه برای دو عدد صحیح (مثبت/منفی/صفر)
- **ساده‌سازی کسر**: تبدیل به ساده‌ترین حالت (مثال: `2/6 → 1/3`، `21/42 → 1/2`، `1.5/3 → 1/2`)
- پشتیبانی از **صورت اعشاری تا ۲ رقم** (مثال: `1.5`، `0.25`)
- اعتبارسنجی کامل با پیام‌های فارسی: مخرج صفر، تقسیم بر صفر، فرمت نادرست، اعشار بیش از ۲ رقم
- رابط فارسی RTL با فونت وزیرمتن
- بدون بیلد، بدون وابستگی — فایل‌های استاتیک خالص

## ساختار پروژه
```
fractial/
├── index.html          # صفحه اصلی
├── css/style.css       # استایل
├── js/
│   ├── fraction.js     # ماژول ریاضی (ESM، بدون DOM)
│   └── app.js          # کنترلر UI
├── tests/
│   └── fraction.test.js
├── package.json
└── README.md           # این فایل
```

## اجرای محلی
```bash
# نصب serve برای پیش‌نمایش (اختیاری)
npm install
npm start
# یا مستقیم باز کردن index.html در مرورگر
```

## اجرای تست‌ها
```bash
npm test
# خروجی نمونه:
# ▶ GCD / LCM
# ✔ GCD / LCM (3.2ms)
# ...
```

## استقرار روی Cloudflare Pages

### روش ۱: آپلود مستقیم در داشبورد (ساده‌ترین)
1. در داشبورد Cloudflare به **Pages** بروید
2. **Create a project** → **Direct Upload**
3. نام پروژه: `fractial` (یا هر نام دلخواه)
4. پوشه‌ی پروژه `fractial/` را zip کنید و آپلود کنید (یا drag & drop)
5. Build settings خالی بگذارید (No build) — Pages فایل‌های استاتیک را مستقیماً سرو می‌کند

### روش ۲: با Wrangler CLI
```bash
# نصب wrangler (اگر ندارید)
npm install -g wrangler
# لاگین
wrangler login
# استقرار
npx wrangler pages deploy . --project-name=fractial
```

> نکته: چون پروژه build ندارد، `build command` و `output directory` خالی می‌مانند.

## تست‌های عملکردی (Sample Cases)
| بخش | ورودی | خروجی پیش‌بینی |
|-----|--------|----------------|
| ساده‌سازی | `2 / 6` | `1/3` |
| ساده‌سازی | `21 / 42` | `1/2` |
| ساده‌سازی | `2 / 4` | `1/2` |
| ساده‌سازی | `1.5 / 3` | `1/2` |
| GCD/LCM | `12 , 18` | GCD=6, LCM=36 |
| عملیات | `1/2 + 1/3` | `5/6` |
| عملیات | `2/3 × 3/4` | `1/2` |
