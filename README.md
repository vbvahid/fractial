# فریکشن (Fractial)

ابزار محاسبات کسری، بزرگترین مقسوم مشترک (GCD)، کوچکترین مضرب مشترک (LCM) و ساده‌سازی کسر — کاملاً سمت‌کلاینت، بدون سرور، برای استقرار روی GitHub Pages.

## ویژگی‌ها
- **عملیات چهارگانه روی ۲ تا ۱۰ کسر**: جمع، تفریق، ضرب، تقسیم — نمایش نام‌ساده‌شده و ساده‌شده
  - به‌صورت پیش‌فرض ۲ کسر نمایش داده می‌شود؛ با دکمه **«+ کسر»** یک کسر اضافه و با **«− کسر»** یک کسر کم می‌شود
  - حداقل ۲ و حداکثر ۱۰ کسر (دکمه‌ها در مرزها به‌صورت خودکار غیرفعال می‌شوند)
  - عملیات از چپ به راست زنجیره‌ای انجام می‌شود: `((f₁ op f₂) op f₃) …`
  - مثال: `1/2 + 1/3 + 1/6 = 1`؛ `1/2 ÷ 1/4 ÷ 1/3 = 6`؛ `(1/2)¹⁰ = 1/1024`
  - کسرهای اضافه‌شدهٔ **خالی** نادیده گرفته می‌شوند، پس می‌توانید کسرها را از قبل کم/زیاد کنید و بعد پر کنید
- **GCD / LCM**: محاسبه برای دو عدد صحیح (مثبت/منفی/صفر)
- **تبدیل کسر به مخرج مشخص (مقسم)**: تبدیل کسر به کسر هم‌ارز با مخرج دلخواه
  - مثال‌ها: `1/2` با مقسم `6 → 3/6`؛ `1/2` با مقسم `3 → 1.5/3`؛ `1/32` با مقسم `8 → 0.25/8`
  - **هر مقسمی پذیرفته می‌شود** — هیچ محدودیتی در تعداد ارقام اعشار صورت خروجی نیست
  - وقتی مقسم مضرب مخرج ساده‌شده باشد، تبدیل دقیق است و صورت کامل نمایش داده می‌شود (`1/3` با مقسم `3 → 1/3`؛ `1/2` با مقسم `1,040 → 520/1040`)
  - در غیر این صورت، نزدیک‌ترین مقدار با گرد کردن محاسبه و با `≈` نمایش داده می‌شود (`1/3` با مقسم `2 → ≈ 0.67/2`)
- **ساده‌سازی کسر**: تبدیل به ساده‌ترین حالت با پشتیبانی از صورت اعشاری (تا ۲ رقم)
  - مثال‌های استاندارد: `2/6 → 1/3`، `21/42 → 1/2`، `2/4 → 1/2`
  - مثال‌های اعشاری‌دوست (مخرج صحیح، صورت تا ۲ رقم): `1/32 → 0.25/8`، `5/8 → 1.25/2`، `1/8 → 0.25/2`
- پشتیبانی از **صورت اعشاری تا ۲ رقم** در ورودی (مثال: `1.5`، `0.25`)
- اعتبارسنجی کامل با پیام‌های فارسی: مخرج صفر، تقسیم بر صفر، فرمت نادرست، اعشار بیش از ۲ رقم
- رابط فارسی RTL با فونت وزیرمتن
- بدون بیلد، بدون وابستگی — فایل‌های استاتیک خالص

## ساختار پروژه
```
fractial/
├── index.html          # صفحه اصلی
├── css/style.css       # استایل
├── js/
│   ├── fraction.js     # ماژول ریاضی (ESM، بدون DOM)
│   └── app.js          # کنترلر UI
├── tests/
│   └── fraction.test.js
├── package.json
└── README.md           # این فایل
```

## اجرای محلی
```bash
# نصب serve برای پیش‌نمایش (اختیاری)
npm install
npm start
# یا مستقیم باز کردن index.html در مرورگر (با سرور محلی به دلیل ماژول ES)
```

## استقرار روی GitHub Pages

این پروژه یک سایت استاتیک است و به راحتی روی GitHub Pages مستقر می‌شود:

### روش پیشنهادی: GitHub Actions (اتوماتیک)
1. مخزن را به GitHub push کنید
2. در تنظیمات مخزن (Settings) → **Pages** → Source را روی **GitHub Actions** بگذارید
3. فایل workflow زیر در `.github/workflows/pages.yml` ایجاد کنید:

```yaml
name: Deploy to GitHub Pages
on:
  push:
    branches: [main]
permissions:
  contents: read
  pages: write
  id-token: write
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/configure-pages@v4
      - uses: actions/upload-pages-artifact@v3
        with:
          path: .
      - uses: actions/deploy-pages@v4
```

4. با هر push به main، سایت به‌روزرسانی می‌شود.

### روش ساده: آپلود دستی (بدون GitHub Actions)
1. در تنظیمات مخزن → **Pages** → Source را روی **Deploy from a branch** بگذارید
2. Branch: `main`، Folder: `/ (root)` انتخاب کنید
3. Save کنید — GitHub Pages به صورت خودکار `index.html` را سرو می‌کند.

> نکته: چون پروژه build ندارد، فقط فایل‌های استاتیک سرو می‌شوند.
